2. **Open the File in Any Browser**

### Option 2: View Live on the Web (GitHub Pages)

If you have enabled **GitHub Pages**, you can view the live site directly online:

👉 **Live Demo:** `https://<your-github-username>.github.io/<your-repository-name>/`

> **Note:** Replace `<your-github-username>` and `<your-repository-name>` with your actual GitHub details.

#### How to enable GitHub Pages (if not already active):

1. Rename `amit-portfolio.html` to `index.html` in your repository.


2. Go to your repository's **Settings** tab.
3. Select **Pages** from the left navigation menu.
4. Under **Build and deployment** > **Branch**, choose `main` (or `master`) and click **Save**.
5. Wait 1–2 minutes, and your live URL will appear at the top of that page!
